## Intervu- built by Anika Kanade

Intervu is an AI-powered technical interview platform that conducts structured interviews based on a candidate's role, experience, and learning background.

Instead of asking the same fixed set of questions, Intervu evaluates each response and can ask follow-up questions when it needs to understand the candidate's knowledge better.

What It Does
-Conducts technical interviews based on the candidate's learning journey
-Asks a minimum of 8 questions across 4 different curriculum days
-Evaluates candidate responses
-Asks follow-up questions when an answer needs more explanation
-Generates a personalized report at the end of the interview
-Identifies strengths and knowledge gaps
-Suggests areas for further improvement


Why Intervu?
Traditional technical interviews can be rigid and don't always give candidates enough opportunity to explain what they know.
Intervu aims to make the process more adaptive and informative by evaluating responses, asking relevant follow-up questions, and providing useful feedback at the end of the interview.
